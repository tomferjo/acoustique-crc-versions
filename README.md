# Acoustique CRC — versions publiées

Ce dépôt ne contient **que les fichiers d'installation** d'Acoustique CRC, l'application de traitement des mesures acoustiques pour l'attestation du respect de la réglementation acoustique des bâtiments d'habitation neufs (arrêté du 26 décembre 2023, guide de mesures de la DGALN). Le code de l'application est dans un dépôt privé ; chaque version y est fabriquée et vérifiée automatiquement, puis déposée ici.

## Télécharger

La dernière version est dans **[Releases](../../releases/latest)** : le fichier **« Acoustique-CRC-*version*-installation.exe »** (environ 55 Mo). Le zip « portable » est un secours : le même programme, à décompresser et à lancer sans installation.

## Installer

1. Enregistrez le fichier d'installation et double-cliquez dessus.
2. Windows affiche sans doute un écran bleu **« Windows a protégé votre ordinateur »** : c'est normal pour un programme qui n'est pas encore signé par un éditeur connu de Windows. Cliquez sur **« Informations complémentaires »**, puis sur **« Exécuter quand même »**.
3. Suivez l'assistant (« Suivant », « Installer », « Terminer »). L'application s'installe dans le dossier des programmes de votre compte, sans droits d'administrateur, et crée un raccourci **« Acoustique CRC »** sur le bureau.

Il faut Windows 10 ou 11, 64 bits. Rien d'autre à installer. Aucune connexion internet n'est nécessaire pour travailler : l'application tourne entièrement sur votre PC, et vos données n'en sortent pas.

## Mettre à jour

Fermez l'application, téléchargez le nouveau fichier d'installation, double-cliquez dessus, suivez l'assistant. Vos paramètres (`Documents\Acoustique CRC`) et vos opérations restent en place. La version s'affiche en bas de l'accueil.

## Version d'essai

Les résultats sont à vérifier par vous, comme avec tout outil nouveau : l'application ne remplace pas votre jugement, et aucune garantie n'est donnée. Merci de ne pas la transmettre sans nous le demander, et de nous dire tout ce qui manque, gêne ou surprend, avec le fichier `Documents\Acoustique CRC\Journal de l'application.txt` (il garde les messages et les erreurs des cinq derniers lancements, rien de vos données).
